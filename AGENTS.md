# Contribution guidelines

Read and follow [CONTRIBUTING.md](CONTRIBUTING.md) before making changes or opening pull requests.
It is the source of truth for contribution scope, coding style, testing, commits, DCO sign-off, review, AI usage, and release notes.

# Pull requests

When opening a pull request:

- Follow `.github/PULL_REQUEST_TEMPLATE.md` and fill in the applicable sections.
- Do not add `Co-Authored-By` trailers for LLMs or AI agents; reserve them for human contributors.
- Add "Created with: <AGENT NAME>" note at the end of the PR body.
